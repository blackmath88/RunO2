The problem

The route works.
The tram data doesn't.

The sensors disagree with each other almost three times as much as two streets differ.

Ranking routes by these readings would be ranking noise while looking confident about it. And this is not a gap more data closes: more trams would improve coverage. They would not solve resolution. Only calibration against reference instruments would — and that comparison was never run for these sensors.

What the numbers actually say

Every figure below comes from the committed evidence — 613,723 tram readings, two national rasters and 18,073 paired sensor-versus-reference hours. The scripts that produced them are in the repository, and a test fails if the page and the evidence ever drift apart.

ACT 1

The trams measure the air

Five microsensors on BVB tram roofs. 613,723 readings of PM2.5 and PM10, each with a position and a timestamp.

ACT 2

Can we plan a run on it?

Join the readings to the 884 km walking network, score candidate loops, keep unmeasured streets visibly unmeasured.

ACT 3

Partly

The temporal signal is real: street rankings genuinely change between morning and evening. That much the data supports.

ACT 4

But not where it counts

Two sensors on the same street in the same hour disagree by more than two different streets differ. The ranking would be noise.

ACT 5

So what would work?

A federal 20 m NO₂ model covers 99.5% of the network with 6× the street contrast — and it is current.

The three gates

Run before building anything on top of the data. A failing gate is a good outcome: it is cheaper to learn in an hour that a dataset cannot carry a recommendation than to discover it after building an interface around one.

What the sensors are worth

Basel also publishes a comparison campaign: low-cost microsensors installed beside the Lufthygieneamt's reference instruments. Pairing them by hour gives the only real error figure for this class of instrument in this city.

µg/m³ PM2.5. These sensors under-report by 32–37% against reference instruments while tracking changes well. A typical hourly error of 4.7–5.9 µg/m³ is about ten times the 0.51 µg/m³ spatial signal runO2 would need to detect — an independent confirmation of the resolution gate. It is a different sensor model and different years from the trams, so it bounds the class; it does not calibrate the tram sensors. That comparison was never run, so runO2 publishes no error band for them.

What would actually make runO2 work

No single dataset does it. Four layers, each doing only what it can — and the planner above already runs on this arrangement.

MODELLED · SPATIAL BASELINE

Federal NO₂, 20 m raster

Annual mean, 99.5% of the walking network, 3.0 µg/m³ between two streets, 8–48 µg/m³ across Basel. Traffic-related — which is what a route choice is about.

Cannot say: today, this hour, or this address.

MEASURED · CURRENT LEVEL

LHA reference stations

Hourly, reference-grade, still updated today. The true level for the city right now, accurate enough to scale the spatial pattern.

Cannot say: which street. Four points for 884 km.

FORECAST · CONDITIONS

Open-Meteo / CAMS

Temperature, rain, wind, European AQI and pollen for the hour you will actually run.

Cannot say: anything that separates two streets.

MEASURED · UNCERTAINTY

Comparison study 100178

What a low-cost reading is worth: −3.07 to −4.62 µg/m³ bias, ~5 µg/m³ typical error, r ≈ 0.88 against reference instruments.

Does not transfer between sensor models.

MEASURED · CORROBORATION

BVB tram sensors

613,723 real observations at street level, temporally rich, across a fifth of the network. Shown beside the ranking — never setting it.

Cannot say: which street is cleaner. Campaign closed March 2020.
