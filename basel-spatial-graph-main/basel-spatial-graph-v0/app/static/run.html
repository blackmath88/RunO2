Clean Air Run

Basel's trams carry air sensors as they cross the city. This plans a running loop around what they measured — and shows you which streets nobody has ever measured at all.

measured a sensor passed this street · unmeasured no sensor ever did — unknown, not clean · dynamic computed for your pace and hour

Exposure is concentration multiplied by time spent breathing it, scaled for running. It is an indicative comparison between routes, not a measure of what you personally inhale, and it says nothing about whether a run is healthy.

Air: Open Data Basel-Stadt · Streets: OpenStreetMap contributors (ODbL) · Timetable: opentransportdata.swiss. Provenance for every value travels into the GPX file as well as onto the screen.
